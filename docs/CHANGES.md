# 变更记录

## 版本规则

应用处于 0.x 阶段。新增功能递增版本号的中间数字 x（如 `0.4.0 → 0.5.0`）；小修正、Bug、图标和样式调整递增末位数字 y（如 `0.4.0 → 0.4.1`）。两类修改都同步更新 `package.json`、锁文件和用户可见说明；文档整理、规则整理和构建脚本维护不单独增加功能版本。

后续每次发布版本，在对应版本标题下填写「新增功能」「Bug 修复」「其他修改」三个小节；App 顶部的「版本更新」面板会自动读取本文件。
